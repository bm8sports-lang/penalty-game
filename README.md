# Penalty Shoot-Out Game

A 2D HTML5 Canvas penalty shootout game inspired by Evoplay's "Penalty Shoot-Out Street".

## Play

Open `penalty.html` directly in a browser, or visit the GitHub Pages URL once enabled.

## Controls

- Click any of the 9 zones inside the goal frame to shoot
- Right corner of screen: 🔇/🔊 toggle music

## Assets

Custom PNG assets go in `assets/`. Missing files automatically fall back to built-in canvas drawings. See `assets/README.txt` for sizing details.

## Audio

Optional `assets/bgm.mp3` — drop in your own (legally owned / royalty-free) audio file. Game works fine without it.
